# Safety signs

Mandatory-action pictograms from ISO 7010, used on machine pages to show the PPE required.

The SVG artwork comes from Wikimedia Commons, as packaged in the MIT-licensed
`@iso-safety-signs/assets` npm package (v2.0.0). Check each sign's Wikimedia Commons page
for the licence of its artwork.

| File | ISO 7010 sign | Used for |
| --- | --- | --- |
| M003.svg | Wear ear protection | Hearing protection |
| M004.svg | Wear eye protection | Safety glasses |
| M008.svg | Wear safety footwear | Safety footwear |
| M009.svg | Wear protective gloves | Gloves, cut-resistant gloves |
| M013.svg | Wear a face shield | Face shield |
| M015.svg | Wear high-visibility clothing | Hi-vis clothing |
| M016.svg | Wear a mask | Dust mask / respirator |
| M026.svg | Wear protective apron | Apron |
| M001.svg | General mandatory action | Long hair tied back, no loose clothing (ISO 7010 has no specific sign) |
